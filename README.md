# ZipGrocer

This project is a Zepto-style grocery storefront built with Vite + React. It showcases a modern grocery delivery landing page with:

- hero with location-based ETA and curated basket preview
- category highlights, lightning deals and delivery timeline
- quick feature highlights and app download call-to-action
- responsive styling tailored for mobile and desktop

## Getting Started

```bash
cd app
npm install
npm run dev
```

Open the app at `http://localhost:5173/`.
